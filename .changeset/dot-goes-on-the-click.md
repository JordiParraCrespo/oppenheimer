A session's sidebar dot goes the moment you click its row. The blue dot of a finished turn waited for the session's pane to load and the API to answer, and the unread mark for the pane to mount; the click now takes either off, and reading a turn drops the session to idle in every list before the API answers (and puts it back if the API refuses).
