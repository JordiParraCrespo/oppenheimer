Bots: `start_session` holds its `task` to the session prompt's own bound (2 KiB, in bytes) and says so to the model, so a long brief is refused as the tool's input error, with the limit, before an approval card is raised. It used to accept 20,000 characters and then fail as "the session would be invalid (prompt)", naming a field the model never wrote; a rejected prompt is now named `task`.
