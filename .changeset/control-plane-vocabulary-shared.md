New importable surfaces for the control plane: `@oppenheimer/shared/scopes` gains the `hosts`, `projects`, `sessions` and `repositories` resources; `@oppenheimer/shared/schemas` gains host, project, session and GitHub installation DTOs plus the primitives they share; `@oppenheimer/shared/agents` is the closed coding-agent catalog; `@oppenheimer/shared/protocol` is the runner link's wire vocabulary, with its JSON Schema emitted at build.
