Plan's tasks have a priority: Urgent, High, Medium or Low, or none (the default). The task dialog has a Priority row, a card shows it with Linear's icons (Urgent is the "!" square), and TODO's Add tasks lists urgent work first. Priority never reorders a column. Bots, `opp tasks add --priority` and the MCP `create_task` can set it.
