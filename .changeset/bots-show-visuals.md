Bots can show visuals: a `show_visual` tool draws a titled card of typed blocks (figures, charts, a table, a checklist, progress and more) in the bot's chat, where the call was made, and keeps it there with the tool calls hidden. A spec that is not a visual is refused with the path of each fault, so the bot fixes it; a turn draws at most six.
