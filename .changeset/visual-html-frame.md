A visual can carry an `html` block, for what the typed blocks cannot draw: the agent's fragment runs in a sandboxed frame on `visuals.<preview domain>`, a static page the preview server serves with the network closed and only the console allowed to frame it. The console posts the fragment and its theme in and takes back only the page's height, its errors and links to open, which ask first. Without a preview domain, or with the `visual_html` flag off, the block shows its source, folded, and the bots' tool refuses it.
