You are setting up this machine as an Oppenheimer host.

1. Check the OS and architecture with uname -sm. Supported: Linux x86_64/arm64, macOS arm64.
2. Confirm git (2.40+) and tmux (3.2+) are installed. If either is missing, install it with the system package manager and report what you installed.
3. Install the runner:
   curl -fsSL https://app.oppenheimer.dev/install.sh | sh -s -- --token opk_7f3a9c
4. The token is single use and expires in one hour. Do not print it anywhere else, and do not store it in shell history.
5. Verify the service is running:
   oppenheimer-runner status
6. Run the preflight and paste its full output:
   oppenheimer-runner preflight
7. If preflight reports claude, codex or opencode missing, stop and ask before installing any of them.
8. Report back: hostname, OS version, CPU count, free disk, and the preflight result.

Do not open inbound ports, change firewall rules, or edit files outside ~/.oppenheimer.
