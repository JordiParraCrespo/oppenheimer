# 0.3 — Kanban

**Goal:** a kanban board linked to projects and everything else. Cards
belong to a project, and a card links to what the work produced:
sessions, branches, pull requests, hosts.

## What exists to build on

- Projects above repositories, with defaults and a grouped sidebar
  (`../versions/mvp/12-projects-on-the-console.md`,
  `../versions/mvp/10-api-modules-and-data-model.md`).
- Note 01's layer table already has a "Board" row: sessions per project
  with live status in the MVP, delegation later.
- 0.2's pull requests and their status, which give a card a column to
  move to without anyone dragging it.

## Questions to answer first

1. What is a card: a task that may start sessions, or a view of sessions
   that already exist? The first adds a table; the second is a
   projection.
2. Do columns move on their own from session and PR state (running,
   waiting on input, PR open, merged), by hand, or both?
3. Does starting a session from a card seed the agent's prompt with the
   card's text?
4. Is the board per project, per workspace, or both?
5. Import from GitHub Issues or Linear, or ours only?
