# oppenheimer

A terminal and VM orchestrator you log in to from anywhere. Open a
browser, pick a machine you own or a fresh VM, get a terminal that
survives everything, type `claude` or `codex`, run thirty of them.

Status: planning. No code yet.

- [`vision/`](vision/README.md): the research notes and the plan, in the
  order they were decided.
- [`vision/brief.html`](vision/brief.html): the one-page brief.

The MVP is a personal workspace of terminal sessions in VMs. See [`vision/07-mvp.md`](vision/07-mvp.md).
